# Evaluation and a possible operating model

## Questions before a pilot

Can a child and caregiver navigate the sample pathway? Can they explain the next step in their own words? Can a caregiver create and correct a useful comfort preference? Can staff understand that preference without assuming it is a guarantee? Do Arabic and accessibility modes support the same tasks?

Use observation and optional short caregiver/staff feedback. Record task completion, misunderstood wording, barriers, and concrete design changes. Agree recruitment, consent, assent where applicable, and safeguarding with the hospital before involving children. A small usability pilot does not establish clinical effectiveness.

Clinical distress outcomes or staff-time savings require a hospital-designed study and appropriate review, with defined instruments, comparison, sample size and analysis. Engagement counts are not clinical outcomes. No participant metrics are implemented or invented in this demo.

If later analytics are introduced, define each event's purpose, obtain the required consent, omit identifiers/free text, and suppress small cohorts using a threshold agreed with the controller. Do not include private notes or passport answers in event payloads.

## Technical targets to measure

Measure initial interaction time, Core Web Vitals, 3D frame rate on a named mid-range phone, memory/context recovery, Arabic layout, keyboard and assistive navigation, and low-bandwidth fallback. Targets are not claimed results. The present production build separates the 3D chunk from initial interface code and caps pixel ratio at 1.5, but no representative 30fps or mobile-network guarantee is made.

## Possible hospital-funded model

A setup fee could cover clinical workflow mapping, local content review, original character/media production, hospital photography and bilingual localization. Annual support could cover hosting, backups, security maintenance, content review cycles, accessibility/device testing, training and support. Model staff and supplier costs separately before proposing prices. Hospital willingness to pay is unvalidated. No child-facing payment, advertising or purchasing flow exists.
