# Security, performance and responsive update — 25 September 2026

## Changes

- Explore offers Ocean pairs and Wanees’ star trail alongside the hospital tour, equipment, preparation games and stories. Quiet Moments owns Star painter, My tiny ocean, Rainbow echoes, bubbles, breathing, beach and garden activities. Old Explore links redirect to the correct quiet activity.
- The female clinician now has a distinct lavender headscarf in the editable Blender scene, compressed GLB, poster and transparent story artwork. The male clinician retains his short-haired appearance. Both still support clothing controls and animation. Replaying a greeting no longer remounts the Canvas. Model cache URLs were revised so existing browsers fetch the new character.
- Static browser policies now cover the local launcher and both deployment proxies: CSP, frame restrictions, MIME protection and referrer controls. CSP permits WebAssembly compilation required by the compressed 3D loader, without enabling general JavaScript unsafe-eval. Caddy adds HSTS for hosted HTTPS.
- Added an overall 300 requests/minute/IP API limit, retained the narrower authentication/chat limits, and capped concurrent model/voice calls at two per API process. Production OpenAPI discovery is disabled. Invalid numeric profile, nickname and date fields are rejected instead of causing exceptions. The local proxy rejects negative, malformed, oversized and unsupported chunked request bodies and strips caller-supplied forwarded headers.
- Chat streams NDJSON through the API and both proxies. The browser displays the user's message immediately and appends the reply as it arrives. Only a completed provider response is saved. Interrupted streams return an error, clear the partial UI reply and preserve the user's input for retry. Leaving the chat aborts the browser request. Responses remain plain React text, not executable HTML. Existing CSRF, account ownership and optimistic concurrency checks still apply.
- Model requests retain the loaded model for 30 minutes, limit recent history to eight messages, bound generated tokens and cap configured CPU threads. Cached conversation state is updated directly after a successful reply. Hashed frontend assets use immutable local/Caddy caching. Shadow maps were reduced and contact shadows render once.
- Mobile chat now keeps the companion visible. Composer and conversation controls wrap on narrow screens, grid children can shrink, and mobile input text is 16px. The chat viewport uses dynamic viewport height.
- Removed the unused Motion dependency, obsolete breathing/player/flower-eye CSS and an unused callback parameter. Enabled TypeScript unused-local/parameter checks. Corrected the asset rebuild command so it reapplies the current cinematic characters rather than leaving the older generator's versions. Offline printable stories and Blender source files remain because they are still used. Only obsolete generated Vite hashes are removed from the Desktop build.

## Verification

- Production frontend build, strict TypeScript, ESLint and 18 Vitest tests across five files pass. Streaming tests cover split UTF-8 Arabic, truncated responses and explicit provider errors.
- Forty real PostgreSQL/API integration checks pass, including CSRF, family/account/role/hospital isolation, lockout, session invalidation, ownership of voice requests, malformed input, persisted streamed completion and no persistence of an interrupted reply. Model output in this suite is a deterministic fixture.
- Separate local-proxy test proves the first streamed chunk arrives before the provider finishes; malformed bodies, security headers and asset caching also pass.
- Actual Three.js GLTF decoding, finite bounds, greeting movement and eye reopening pass for the rebuilt female clinician. Both male and female selections were visually checked in the browser.
- Fully loaded Explore, Quiet Moments, memory, maze, aquarium, music and chat routes checked at 320, 768 and 1440px: no horizontal document overflow. Arabic Explore/Quiet Moments/guide checked at 390px. Authenticated mobile chat sent and displayed a real reply at 390px with no captured console errors.
- Actual qwen3:0.6b model, authenticated API and local streaming proxy: first words **1.28 seconds**, completed/saved reply **7.64 seconds**, 24 delta events. See REAL-STREAM-CHECK.json. Earlier non-streaming samples took 47.74 and 37.73 seconds. These are individual local observations, not controlled benchmarks or guaranteed service times; prompt, model warmth, answer length and hardware differ.
- npm audit and NuGet transitive vulnerability audit reported no known vulnerable packages at check time. This is a targeted hardening and regression pass, not a penetration test or guarantee of no vulnerabilities. Hosting still needs correct TLS/proxy configuration, backups, updates and realistic load testing. AI content quality and Arabic speech synthesis need separate deployment evaluation.

Streaming API: POST /api/v1/chat/conversations/{id}/messages with `{text, version, stream:true}`. Events are `start`, `delta` (text), `complete` (persisted result) or `error` (title). Omitting stream preserves the JSON-response API. Private replies and sessions remain no-store.
